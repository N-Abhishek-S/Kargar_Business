# AI Engineering Operating System - Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-21

### Added
- **Phase 1:** Core governance (`CLAUDE.md`), `registry.md`, and `capabilities.md` mapping domains.
- **Phase 2A:** Core Standards for TypeScript, React, Vite, Tailwind, and Git.
- **Phase 2B:** Platform Standards for Supabase, Database, Security, Testing, Performance, Accessibility, SEO, and Observability.
- **Phase 3:** Capability Engine including `skills/`, `commands/`, `personas/`, and `research/` workflows.
- **Phase 4:** Engineering Blueprints (`react_feature.md`, `supabase_edge_function.md`, `database_migration.md`, `github_actions_ci.md`).
- **Phase 4:** Executable Checklists (`pr_review.md`, `security_review.md`).
- **Phase 4:** Automation orchestration (`new_feature.md`).
- **Phase 6:** Self-evolution maintenance files (`CHANGELOG.md`, `ROADMAP.md`).

### Changed
- Migrated standard documentation to strict templating requiring explicit globs and cross-referencing.
- Decoupled TypeScript standard from React standard to allow universal backend/frontend application.
