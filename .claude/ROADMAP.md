# AI Engineering Operating System - Roadmap

## Current Status: Version 1.0.0
The OS has established governance, standards, active capabilities, and executable blueprints tailored for the KargarWeb tech stack (React 19, Supabase, Tailwind, Vite).

## Immediate Next Step: The Feedback Loop
As directed, we will **halt generation of governance documents** and immediately test the OS on a real-world feature implementation within KargarWeb. 

### Goals for the Pilot Implementation
- [ ] Use `/feature` and `/component` commands exclusively to build the feature.
- [ ] Ensure `new_feature.md` automation workflow succeeds without human intervention.
- [ ] Identify and patch any friction, missing context, or duplication in the `.claude/` framework.

## Future Horizons

### Q3 2026: The Core vs Project-Pack Split
Extract the `.claude/` directory into two distinct layers:
1. **AI Engineering OS Core**: Reusable forever (Standards, Skills, Checklists).
2. **Project Packs**: Hardened, domain-specific overrides (Kargar, SkillGuru, Prezenti).

### Q4 2026: Quarterly Maintenance Cycle
- **Dependency Audit**: Review React 19 / Vite updates against `standards/vite.md`.
- **Security Review**: Full execution of `checklists/security_review.md` on production database.
- **Performance Profiling**: Execution of `research/investigate_performance.md` on core user flows.
