# Domain Registry

This registry tracks the formally recognized engineering domains within this repository. 
Do not invent new domains without demonstrating substantial reusable value across multiple projects.

## Validated Domains (Phase 0 Discovery)

### Core Technologies
- `react`: React 19, Hooks, Server Components, Context.
- `typescript`: TypeScript 6.0, strict typing, Zod validation.
- `tailwind`: Tailwind CSS 4.3, custom configurations.
- `supabase`: PostgreSQL, Row Level Security (RLS), Auth, Storage, Edge Functions.

### Architecture & Engineering
- `frontend`: Component boundaries, state management, routing.
- `backend`: API design, database schemas, function triggers.
- `performance`: Core Web Vitals, Vite optimization, lazy loading.
- `security`: OWASP, Supabase RLS, input sanitization.
- `animations`: Framer Motion, GSAP integrations.
- `testing`: Unit tests, integration tests (Vitest, Playwright).
- `devops`: Vercel deployments, GitHub Actions CI/CD.

*To register a new domain, submit an Architecture Decision Record (ADR) justifying its necessity.*
