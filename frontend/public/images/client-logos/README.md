/* 
  Client Logo Assets
  ==================
  This folder contains locally-managed client logo images.
  
  To add a new logo:
  1. Save the logo image (SVG preferred, PNG/WebP accepted) in this folder
  2. Name the file using kebab-case matching the company name, e.g.:
     - powercon.svg
     - tata-batteries.png
     - eicher.webp
  3. Update the CLIENT_LOGO_MAP in src/components/ui/logos/logoAssets.ts
  
  Naming Convention:
  - Use lowercase kebab-case
  - Prefer SVG for scalability
  - Ensure logos have transparent backgrounds where possible
  - Keep file sizes under 50KB for performance
*/
